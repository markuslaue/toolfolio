# Software-Kategorien final, OMR + Capterra zusammengefuehrt

OMR und Capterra vereint, ueber den deutschen Rubriknamen entdoppelt. Ergebnis: **1315 eindeutige Kategorien**. Der Slug ist aus der deutschen Rubrik abgeleitet (Verzeichnisname = Slug), Umlaute als ae/oe/ue/ss.

Quelle: beide = in OMR und Capterra, sonst die jeweilige Quelle.

Prioritaeten: **PRIO 1** Name enthaelt 'Software'. **PRIO 2** klarer Tool-/System-/Plattform-/Programm-Bezug (auch in Komposita) oder Software-Akronym. **PRIO 3** kein klarer Software-Bezug im Namen mehr.

Verteilung: PRIO 1 = 724, PRIO 2 = 352, PRIO 3 = 239.
