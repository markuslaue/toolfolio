# Production-Guides

Diese Setup-Guides werden beim ersten Deployment (`/deploy`) befuellt bzw. ergaenzt. Geplant:

- `error-tracking.md` - Fehler-Tracking (Sentry o. ae.) einrichten
- `security-headers.md` - Security-Header in `next.config` (CSP, HSTS, X-Frame-Options ...)
- `performance.md` - Lighthouse/Core-Web-Vitals-Check (Ziel > 90, besonders fuers SEO-Verzeichnis)
- `database-optimization.md` - Indizes, RLS-Pruefung, Supabase-Performance
- `rate-limiting.md` - optionales Rate-Limiting fuer API-Routen

Die `/deploy`-Skill (Hostinger-Variante) verweist auf diese Dateien.
